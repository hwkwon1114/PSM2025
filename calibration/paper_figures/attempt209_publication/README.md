# Attempt 209 publication figures

Seven reproducible PDF and PNG figures with accompanying captions. Shape figures use corrected-convention forward evaluations at the frozen historical Attempt 209 parameters. Optimization history and post-hoc sensitivity use the older historical objective and are not on the same scale as the corrected shape scores. Runs 2 and 3 are exploratory transfers, not unseen validation. The GP is a conditional retrospective diagnostic, not a physical sensitivity or parameter confidence interval. Figures do not establish global optimality. No solver or search was run. See `provenance.json` and `calibration/analysis/attempt209_publication.py` for data identities and settings. The horizontal, larger-type x–y and 3-D overlays were subsequently rendered by `calibration/analysis/attempt209_horizontal_overlays.py`, which verifies the saved input identities and reuses the original scan sample. It stages its outputs in a new `run/attempt209_horizontal_*` directory for inspection before copying them here. The five remaining figures were restyled with uniform 16 pt text by `calibration/analysis/attempt209_restyle_other_figures.py`, which verifies input identities and the historical GP curves. All seven figures use 16 pt text at their exported page sizes; the text becomes smaller if the figures are scaled down for a manuscript.
