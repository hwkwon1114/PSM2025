# Final shape overlaps for the three pairwise calibrations

Rows show the lowest-valid-objective frozen fits calibrated on Runs 1+2, 2+3 and 1+3; columns show Runs 1, 2 and 3. Each panel overlays the saved experiment (orange points) with the saved simulation (blue grid). The excluded run in each row is labeled as an exploratory check, not blind validation: all runs had previously been seen. Titles report the full shared-footprint symmetric surface RMS in mm, not an RMS of the displayed point sample. For visual clarity, 2,500 scan points per case were uniformly sampled without replacement using deterministic seeds 20261029, 20261030 and 20261031; the same points are used in all three rows for that case. Simulation grid lines are piecewise-linear interpolations on saved model facets, masked beyond the mesh; neither surface was refit or smoothed. Both inputs are the saved material-frame scored surfaces, without a new registration. Public coordinates are x = width, z = length and y = height; internal v is shifted by +65 mm. All panels use identical limits, camera and 8× height-axis exaggeration; numeric tick values remain in mm. Spatially dependent points are not independent replicates. Full error aggregates and directional p95 are in pairwise_case_error_comparison and pairwise_floor1_results.md.
