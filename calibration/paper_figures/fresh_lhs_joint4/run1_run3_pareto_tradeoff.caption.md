# Run 1–Run 3 calibration trade-off

Observed symmetric shared-footprint surface RMS discrepancies for the fresh joint LHS-to-BO search. Both axes are training/calibration cases in millimetres; lower is better. (a) All 86 valid candidates, with logarithmic axes. (b) Linear-scale detail showing 33 of those candidates; the other 53 lie outside the detail limits. Crosses are valid LHS points; dots are valid BO points. Blue rings identify the 9 points not dominated by any other valid saved candidate; the star is the selected minimum of J = sqrt((E1² + E3²)/2). The three text labels mark the smallest observed Run 1 discrepancy, the selected minimum J, and the smallest observed Run 3 discrepancy. Each point is a shared four-parameter set, not an independent experimental replicate.

The full search contains 88 attempts; 2 invalid attempts have no plottable pair and are excluded, not assigned penalty coordinates. The search optimized the single joint objective, not a multiobjective acquisition, so the nondominated subset is an observed frontier only—not a proven global frontier or evidence of an irreducible trade-off. Candidate results are adaptive, both cases were used for calibration, and no uncertainty interval or held-out validation is implied. The BO bounds and model were informed by earlier work. No solver, new optimization, scan scoring or Run 2 data was used for this figure.
