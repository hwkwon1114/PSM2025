# Decisions

- **2026-11-01 — BO-RUN2-RUN3 approved.** The researcher approved running independent clean Bayesian calibrations on physical specimens Run 2 (`run9`) and Run 3 (`run10`) to test whether the calibrated parameter basin ($g_{\text{top}} \approx 2.4 \times 10^{-4}$, negative top orthotropy) is universal across specimens or specimen-specific. The protocol mirrors `run1_clean_24lhs` exactly (24 LHS + Log-EI, 4 active parameters with fixed hardening, early stopping $<0.5\%$). Both jobs submitted concurrently to Quest Slurm. Outputs: `run/run2_clean_24lhs/` and `run/run3_clean_24lhs/`.
- **2026-11-01 — EDGE-ANCHOR-1 approved.** The researcher approved `cards/EDGE-ANCHOR-1.md` as drafted, with gates G1 (|centre| ≤ 0.5 mm, |yaw| ≤ 0.2°), G2 (|ΔJ|/J ≤ 1 % for J < 2 mm) and G3 (no rank inversions). Rationale: keep the double-sided RMS; never fit pose per candidate, because the scan and the model start from the same flat sheet, so edge misalignment is real error, and earlier rotation fits biased the score by dropping edge points. Only the scan's fixed placement is in question. Solver-free; running jobs unchanged.
- **2026-11-01 — EDGE-ANCHOR-1 outcome.** G1 passed on all scans. G2 failed on Run 3 (≤ 4.8 µm changes, which are > 1 % only for J ≈ 0.16–0.28 mm) and G3 failed through near-tie rank swaps (≤ 1.14 µm apart). The researcher agreed to adopt edge-anchored scan placement (variant A) for **future** campaigns only. Completed campaigns and the running `run1_clean` job (Slurm 6653633) are unchanged. Production code (`calibration/ewcal/material_frame.py`) is not yet changed; the change needs its own pre-execution review before any campaign uses it.
- **2026-11-04 — REPLICATE-HW1 approved.** The researcher approved `cards/REPLICATE-HW1.md` as drafted: a blind forward prediction of collaborator scan "Hyunwoo Run 1" (24 passes) with the frozen Attempt 209 parameters; back-face passes swap gtop↔gbot and ortho_top↔ortho_bottom (researcher instruction). Confirmed: sheet 220 × 124 × 0.61 mm; CSV back-face rows are in the front-view frame. One 2 mm solve after verifier review; no fitting to the scan; 1 mm check not authorized.
- **2026-11-09 — Run consolidation adopted & Cal-Run 7 removed.** The researcher approved consolidating physical experiment labels into two unambiguous series: Calibration specimens ($200 \times 300 \times 0.77\text{ mm}$) are `Cal-Run 1` (`run6`), `Cal-Run 2` (`run9`), and `Cal-Run 3` (`run10`); Collaborator shape-design validation specimens ($220 \times 124 \times 0.61\text{ mm}$) are `Val-Run 1` (formerly Hyunwoo Run 1; 24 passes, double-sided, saddle shape) and `Val-Run 2` (formerly Run 3; 30 passes, single-sided, trough/dimple shape). Machine Run 7 (`run7`) was removed from the repository. Documented in `cards/RUN-CONSOLIDATION.md`.
